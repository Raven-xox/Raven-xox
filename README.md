## `01 — SIGNAL`

> **I don't want to just use technology. I want to know what happens underneath it.**

I'm a 3rd-semester **CSE (Cybersecurity)** student who got way too interested in what happens when you stop treating a system like a black box and start poking at it.

Cybersecurity caught my attention because there is always another layer underneath:

**What does it do?**
**Why does it do that?**
**What happens if I change this?**
**Why did I just break it?**

That's basically how I learn.

I would rather build something badly, break it spectacularly, debug it for three hours and finally understand **why** it works than memorize something I'll forget next week.
